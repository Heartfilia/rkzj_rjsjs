# 软考·软件设计师 刷题站（精简版）

一个**双击就能用**的本地刷题页面：登录、题库、随机/错题/每日/章节练习、进度统计都有了，
但不需要服务器、不需要数据库、不需要账号系统。

打开方式：

```
dist/软件设计师-刷题.html
```

双击即可（Chrome / Safari / Edge 都行）。答题记录存在浏览器 localStorage 里，
换设备或清缓存会丢——自用够，别当唯一存档。

> ⚠️ 如果在**预览框 / 沙箱 iframe** 里打开，页面顶部会出现一条黄色提示，
> 说"不能写本地存储"。这不是坏了：预览框禁用了 localStorage，程序会自动降级成内存模式，
> 判分和解析照常工作，只是这次的记录不落盘。用浏览器直接打开这个文件就正常。

## 两种用法

| | 离线版 | 线上版 |
|---|---|---|
| 入口 | `dist/软件设计师-刷题.html` 双击 | 域名（nginx 反代） |
| 题库 | 内联在 html 里（1.9 MB） | 首屏只取 `/api/index` 索引（gzip 约 10 KB），题目正文按需取；进度走 `/api/state` |
| 记录 | 浏览器 localStorage | 服务端 SQLite，换设备也在 |
| 账号 | 无 | 密码登录，不同密码 = 不同用户 |
| 后端 | 无 | `server/app.py`（纯标准库，40–60 MB 内存） |

部署细节见 [server/DEPLOY.md](server/DEPLOY.md)。

**加题库不用改代码。** 按上面结构丢文件即可：

```
banks/高级/系统架构设计师/bank.json
banks/高级/系统架构设计师/综合知识/2024-11.json
```

然后 `python3 scripts/build_app.py`。只要有第二个题库，页面顶部会自动出现题库切换器。
`bank.json` 里 `chapters` 决定章节标签和章节练习的分组。

## 重新生成

```bash
# 只在重新解析 PDF 时需要（要求 pypdf）
PYTHONPATH=.tools/pylibs python3 scripts/parse_papers.py

# 平时只需要这一步：扫 banks/ 打包
python3 scripts/build_app.py
```

依赖只装在了 `.tools/pylibs`，没污染系统环境。

| 2018 上 | 1 套 | ✅ 已入库 34 题（**真题 docx 提供题干选项 + 答案 docx 提供答案**，两份合并） |
| 2019 上/下 | 2 套 | ❌ 答案只存在于**扫描版 PDF**（文字层只有 192 字符），必须先 OCR |

docx 这条线比 PDF 干净得多：没有页脚广告、表格不塌、解析自带。但它每年排版都不一样，
`parse_docx.py` 目前只吃 `【答案】/【解析】` 这一种（2009–2017 通用）。

## 数据是怎么来的（以及它有多脏）

三套卷子三种排版，所以 `parse_papers.py` 里按卷配置了两种适配器：

- `numbered`：行首 `12、` 起题（2020-11、2022-05）
- `paren`：题干在前，`（12）A. ...` 标题号与选项，答案在卷末答案表（2022-11）

实测下来，**原始 PDF 的质量比预想的差**：

| 卷子 | 情况 | 结果 |
|---|---|---|
| 2020-11 | 号称"真题及答案解析"，实际缺 41–47 题，75 题里只抽到 57 题、52 个答案 | 用，但残缺 |
| 2021-05 | 纯空白试卷，全卷 0 答案 | 跳过 |
| 2021-11 | App 导出排版，只有末尾英语题带答案 | 跳过 |
| 2022-05 | 只有前 34 题，但每题都有答案 + 解析 | 用，最干净的一份 |
| 2022-11 | 75 题完整，答案表齐全，但**没有解析** | 用 |

所以 131 道里只有 60 道带原卷解析。这不是解析没做，是**原卷就没有**。

## 已知问题

1. **题量少**：131 道只够"试一下"。要做到 1500+ 道，得把 2023–2026 的扫描件用视觉模型转写，
   或者把 `章节刷题题库-软件设计师-有答案版.pdf`（27MB）解析下来——那个下载一直失败，没做完。
2. **专业英语只有 1 题**：其余 4 题的题干是共享的一整段英文原文，抽取时被并到一题里了，
   剩下 4 题没题干所以被过滤掉了。
3. **题干偶有断行/错字**：PDF 换行没完全还原，比如"参 数"这种中间带空格的。
4. **答案可能有错**：回忆版真题本来就可能有争议答案，别盲信。
5. **没有做双空题**：一道题两个空（如"平均 CPI 为（ ），MIPS 为（ ）"）判分逻辑是单选，
   这类题被标记 `multiBlank` 过滤掉了。

## 考试日期怎么改

首页倒计时读的是 `app/template.html` 里的 `EXAMS` 常量：

```js
const EXAMS = [
  { name:'2027 年上半年', signStart:'2027-03-16', signEnd:'2027-04-13',
    examStart:'2027-05-22', examEnd:'2027-05-23', predicted:true },
];
```

`cycleStart` 是**本轮备考周期的起点**，进度条按 `(今天 - cycleStart) / (考试日 - cycleStart)` 计算，
每天涨一点。换周期时记得一起改。

现在填的是**预测日期**（软考上半年历年在 5 月第 4 个周六：2024/5/25、2025/5/24、2026/5/23），
官方一般次年 2–3 月才发公告。拿到正式日期后改这里、重跑 `build_app.py` 即可；
`predicted:false` 会把右下角那行提示换成"官方公布日期"。

## 解析补全（data/analyses.json）

原卷里没有解析、或解析是坏的（"见第 12 题""2016 年 11 月第 10 题"、只剩一行选项、混入答案字母）的题，
统一补在 `data/analyses.json` 里，构建时**只覆盖空解析或明显残缺的**，原卷解析优先保留。

```json
{ "sd-202211-01": "RISC 的设计思路是……" }
```

页面上这类解析会标 **「解析 · 补写」**，方便你区分。

当前状态：1186 道可用题 **全部有解析**，其中 197 道为补写。
